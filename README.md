# DuoPrototype

一个 macOS Duo 风格状态栏应用原型。

当前版本已经接入本机状态，展示：

- 电量圆环、充电闪电和低电量颜色
- Wi-Fi、以太网、断网状态
- 个人热点连接自动识别（按 macOS 的计费网络标记显示热点图标）
- 四级音量和静音状态
- AirPods / 蓝牙耳机临时状态
- 菜单栏小图标和点击后的状态面板
- 深色与浅色外观
- 实时读取 Mac 电量和充电状态
- 实时读取 Wi‑Fi / 以太网 / 断网状态
- 实时读取当前系统输出音量和输出设备名称
- 蓝牙耳机与内置扬声器的多通道音量读写，并与系统实际音量回读同步
- 菜单栏点击后展开控制面板
- 应用启动后不自动打开大窗口；仅从面板内点击“控制中心”进入
- 控制面板可调音量、静音、查看充电预计完成时间并打开系统设置
- 低电量模式状态与快捷切换；系统权限不足时自动跳转电池设置
- 自动监测 CPU、内存和热压力，仅在需要关注时持续显示
- 可选登录启动
- 状态变化时平滑更新，并在充电、低电量、断网、耳机连接时显示短暂提示
- 静音时保留音量数值，但菜单栏和预览中的四个音量点全部变灰
- 桌面与通知中心 WidgetKit 小组件（小号、横向两种尺寸）

## 运行

需要 macOS 14 或更高版本，以及 Xcode Command Line Tools。直接运行源码：

```bash
swift run
```

也可以构建一个本地应用包（包含 WidgetKit 扩展）：

```bash
./scripts/build-app.sh
open .build/DuoPrototype.app
```

启动后会打开视觉预览窗口，并在菜单栏添加一个 Duo 图标。应用只读取本机系统状态，不向外部服务器发送数据。

当前版本为了避免额外的定位授权，只显示 Wi‑Fi 连接状态，不读取 SSID 名称。系统输出设备会根据名称尽力识别 AirPods 或蓝牙耳机。菜单栏控制面板已经接入音量设置和系统设置快捷入口。

`outputs/DuoPrototype-0.5.0.zip` 是当前构建好的 Apple Silicon 本地原型。它使用本机 ad-hoc 签名，只用于自己的 Mac 测试，不代表 Apple Developer ID 公证版本。首次运行后，在桌面或通知中心的“编辑小组件”里搜索“Duo 状态”即可添加。
